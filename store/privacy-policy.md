# Política de privacidad de Pluma

*Última actualización: 29 de septiembre de 2026*

Pluma es un editor de Markdown para Windows desarrollado por Mauricio Bridge y distribuido como software libre (GPL-3.0).

## Qué datos recopila Pluma

**Ninguno.** Pluma no tiene cuentas de usuario, publicidad, análisis de uso ni telemetría. No envía a nadie, ni al autor ni a terceros, tus documentos, tu información personal ni datos sobre cómo usas la aplicación.

## Qué se guarda en tu equipo

- **Tus documentos:** donde tú los guardes. Pluma solo lee y escribe los archivos que abres, guardas o exportas.
- **Tus preferencias:** tema, tamaño de letra, disposición de la ventana, último documento abierto y última carpeta del explorador. Se guardan en un archivo de configuración local (`pluma.ini`) y nunca salen de tu equipo.

## Conexiones a internet

- **Versión de Microsoft Store:** Pluma no se conecta a internet. Las actualizaciones las entrega Microsoft Store.
- **Versión del instalador o portable (GitHub):** si la comprobación de actualizaciones está activada (se desactiva en *Configuración > Preferencias*), Pluma consulta como máximo una vez al día la API pública de GitHub para saber si hay una versión nueva, y descarga el instalador solo si tú aceptas actualizar. Esa consulta no incluye datos personales. GitHub recibe la información técnica de cualquier conexión (dirección IP y versión de Pluma en el agente de usuario), según su propia política de privacidad.
- **Enlaces:** al hacer clic en un enlace de un documento, Pluma lo abre en tu navegador predeterminado. A partir de ahí aplica la política del sitio que visitas.

## Menores de edad

Pluma no recopila datos de nadie, tampoco de menores de edad.

## Cambios en esta política

Si esta política cambia, se publicará la versión nueva en esta misma dirección con la fecha de actualización.

## Contacto

Para preguntas sobre privacidad, abre un *issue* en https://github.com/mbridge1eafit/Pluma-Editor/issues.

# Pluma Privacy Policy

*Last updated: September 29, 2026*

Pluma is a Markdown editor for Windows developed by Mauricio Bridge and distributed as free software (GPL-3.0).

**Data collected: none.** Pluma has no user accounts, ads, analytics or telemetry, and sends no documents, personal information or usage data to the author or to third parties.

**Stored on your device:** your documents, wherever you save them, and your preferences (theme, font size, window layout, last document and folder) in a local configuration file (`pluma.ini`) that never leaves your device.

**Internet connections:** the Microsoft Store version makes no network connections; the Store delivers its updates. The installer and portable versions from GitHub check the public GitHub API for a new version at most once a day, if update checks are enabled, and download the installer only when you accept an update. GitHub receives the technical information of any connection (IP address, Pluma version in the user agent). Links in documents open in your default browser.

**Contact:** https://github.com/mbridge1eafit/Pluma-Editor/issues
