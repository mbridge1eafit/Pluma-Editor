# Clasificación por edad (cuestionario IARC)

Partner Center > envío > **Clasificaciones por edad**. El cuestionario es de la IARC y calcula la clasificación de cada región (ESRB, PEGI, USK, ClassInd…). Las preguntas exactas pueden cambiar. El criterio es que Pluma es un editor de texto local, sin contenido propio ni funciones sociales.

## Tipo de aplicación

**Utilidad, productividad, comunicación u otro** (*Utility, Productivity, Communication, or Other*). No es un juego, ni una red social, ni una tienda, ni un servicio de streaming.

## Respuestas

| Pregunta | Respuesta | Motivo |
|---|---|---|
| Violencia, sangre o terror | No | Pluma no trae contenido. Solo muestra lo que escribe el usuario. |
| Contenido sexual o desnudos | No | Igual que arriba. |
| Lenguaje soez o discriminatorio | No | Igual que arriba. |
| Drogas, alcohol o tabaco | No | Igual que arriba. |
| Juegos de azar, o apuestas con dinero real o simulado | No | |
| ¿Los usuarios pueden interactuar o intercambiar contenido con otros usuarios? | No | No hay chat, cuentas ni publicación en línea. |
| ¿Comparte la ubicación física del usuario? | No | |
| ¿Permite comprar bienes digitales? | No | Es gratis y sin compras dentro de la aplicación. |
| ¿Da acceso sin restricciones a internet (navegador o buscador)? | No | No es un navegador. Los enlaces de un documento se abren en el navegador predeterminado del sistema, fuera de Pluma. |
| ¿Recopila datos personales o los comparte con terceros? | No | Sin telemetría. Ver `privacy-policy.md`. |

**Resultado esperado:** apta para todas las edades (ESRB «Everyone», PEGI 3 o equivalente). El certificado de la IARC llega por correo; guárdalo.
